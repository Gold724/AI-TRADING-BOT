# VNC Quick Reference - AI Trading Sentinel

## 🚀 QUICK START COMMANDS

### 1. Access VNC Console
→ https://my.contabo.com → Your Services → VPS → VNC Console

### 2. Open Terminal in VNC
→ Right-click desktop → Open Terminal
→ OR: Ctrl + Alt + T

### 3. Execute Deployment
```bash
cd /home/ubuntu
wget https://raw.githubusercontent.com/your-username/ai-trading-sentinel/main/vnc_deployment_implementation.sh
chmod +x vnc_deployment_implementation.sh
./vnc_deployment_implementation.sh
```

### 4. Configure .env (when gedit opens)
- Replace: your_username_here → actual username
- Replace: your_password_here → actual password
- Save: Ctrl + S
- Close: Alt + F4

### 5. Verify Service
```bash
sudo systemctl status trae-bot
sudo journalctl -u trae-bot -f
```

## 🔧 ESSENTIAL COMMANDS

### Service Management
```bash
# Check status
sudo systemctl status trae-bot

# Start service
sudo systemctl start trae-bot

# Stop service
sudo systemctl stop trae-bot

# Restart service
sudo systemctl restart trae-bot

# Enable auto-start
sudo systemctl enable trae-bot

# View logs
sudo journalctl -u trae-bot -f
tail -f /var/log/trae/trae.log
```

## 🆘 TROUBLESHOOTING

### VNC Issues
- Try different browser
- Disable browser extensions
- Use incognito/private mode
- Contact Contabo support

### Service Won't Start
```bash
# Check detailed logs
sudo journalctl -u trae-bot -n 50

# Check service file
sudo systemctl cat trae-bot

# Reset and restart
sudo systemctl daemon-reload
sudo systemctl restart trae-bot
```

### Browser Fails
```bash
# Reinstall Playwright
python3 -m playwright install
python3 -m playwright install-deps

# Set display
export DISPLAY=:1

# Test manually
python3 browser_test.py
```

### Permission Issues
```bash
# Fix log permissions
sudo chown ubuntu:ubuntu /var/log/trae/trae.log
sudo chmod 644 /var/log/trae/trae.log

# Fix directory permissions
sudo chown -R ubuntu:ubuntu /home/ubuntu/ai-trading-sentinel
```

## 🔐 SECURITY

### Change Default Passwords
```bash
# Change ubuntu user password
sudo passwd ubuntu

# Change root password
sudo passwd root
```

### Firewall Setup
```bash
# Enable firewall
sudo ufw enable

# Allow SSH (if needed later)
sudo ufw allow 18177

# Allow HTTP/HTTPS (if web interface)
sudo ufw allow 80
sudo ufw allow 443

# Check status
sudo ufw status
```
