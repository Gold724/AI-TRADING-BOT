## 🔧 Windows SSH Solutions

### Option 1: Install OpenSSH Client (Recommended)
```powershell
# Check if SSH is installed
Get-WindowsCapability -Online | Where-Object Name -like 'OpenSSH*'

# Install OpenSSH Client if missing
Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0

# Verify installation
ssh -V
```

### Option 2: Use Windows Subsystem for Linux (WSL)
```powershell
# Install WSL if not present
wsl --install

# Use SSH from WSL
wsl ssh -p 18177 root@161.97.112.146
```

### Option 3: Use PuTTY (GUI Alternative)
1. **Download**: https://www.putty.org/
2. **Configure**:
   - Host Name: 161.97.112.146
   - Port: 18177
   - Connection Type: SSH
   - Username: root
3. **Connect**: Click "Open"

### Option 4: Use Git Bash (If Git is installed)
```bash
# Open Git Bash and run:
ssh -p 18177 root@161.97.112.146
```

## 🚀 VPS Recovery Commands (Once Connected)

### Via Contabo Web Console
```bash
# Check VPS status
uptime
df -h
free -m
ps aux | grep python

# Check SSH service
systemctl status ssh
systemctl status sshd

# Check SSH configuration
cat /etc/ssh/sshd_config | grep Port

# Check listening ports
ss -tlnp | grep ssh
netstat -tlnp | grep ssh

# Fix SSH if needed
sudo systemctl restart ssh
sudo systemctl enable ssh

# Check firewall
ufw status
iptables -L

# Allow SSH ports
ufw allow 22/tcp
ufw allow 18177/tcp
```
